How to use

Drag any white dot up/down to boost or cut that frequency band (-25 to +25 dB).
Left slider = overall volume. Bass Boost loads a warm low-end curve.
Reset Filters flattens everything. Spectrum Visualizer (left button) draws live frequency bars behind the curve.
Stop EQing is now per-site: it remembers on/off for each website (e.g. on for YouTube, off for Netflix). Volume still applies.

Presets

Type a name, hit + Save Preset. Pick a saved name from the box to load it; - Delete Preset removes it.

If audio goes silent

Another audio extension (e.g. AIRS) grabbed the stream first. Disable it and reload the tab.

Web Audio EQ

Custom 13-band Web Audio equalizer for any website's audio & video. Re-applies itself on every track change, so your settings never reset between songs.

Runs on all sites (YouTube, SoundCloud, Spotify web, etc.). EQ settings are shared across all tabs.
Web Audio EQ Automatically EQs while audio is playing!
